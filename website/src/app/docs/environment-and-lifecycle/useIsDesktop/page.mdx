# useIsDesktop

### Determines if the current viewport width meets or exceeds a specified desktop breakpoint.

<Blockquote.Tip>
  <Blockquote.Content>While this hook is convenient, for simple layout changes, consider using <strong>CSS Media Queries</strong> first to avoid the "flash of unstyled content" (FOUC) during the initial hydration.</Blockquote.Content>
</Blockquote.Tip>

#### Installation

<CodeBlock
  code={`npm install @vibehooks/react/useIsDesktop`}
  language="bash"
/>

#### Description

A responsive utility hook that monitors window resizing and returns a boolean state indicating if the current screen width is greater than or equal to a provided pixel value. It leverages **useScreenSize** for centralized event listening.

#### Source code

```tsx
'use client';

import { useIsDesktop } from "@vibehooks/react/useIsDesktop";
import { Tag } from "@/components/ui/Tag";
import { Layout } from "@/layouts/Layout";

export default function Demo() {
  const isDesktop = useIsDesktop(1024);
	return (
		<Layout>
      <Layout.Title>Verifying Desktop View</Layout.Title>
      <div className="flex flex-col items-center gap-1.5">
        <Layout.Caption>Current environment</Layout.Caption>
        <Tag.Primary>{isDesktop ? "🖥️ Desktop View" : "📱 Mobile/Tablet View"}</Tag.Primary>
      </div>
		</Layout>
	);
}
```
