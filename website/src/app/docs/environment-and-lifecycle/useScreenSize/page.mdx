# useScreenSize

### Returns the current inner dimensions of the browser window.

<Blockquote.Caution>
	<Blockquote.Content>
		###### Frequent resizing can trigger many re-renders. If you only need to react to specific breakpoints, consider using <strong>useIsDesktop</strong> or a{' '}<strong>matchMedia</strong> based hook instead for better performance.
	</Blockquote.Content>
</Blockquote.Caution>

#### Installation

<CodeBlock code={`npm install @vibehooks/react`} language='bash' />

#### Description

A reactive hook that tracks the **window.innerWidth** and **window.innerHeight**. It attaches a single resize listener on mount and cleans it up on unmount, providing a real-time object of the viewport dimensions.

#### Source code

```tsx
'use client';

import { useScreenSize } from '@vibehooks/react';
import { Layout } from '@/layouts/Layout';

export default function Demo() {
	const { height, width } = useScreenSize();

	return (
		<Layout>
			<Layout.Title>Screen Size</Layout.Title>
			<div className='flex flex-col items-center max-w-48 w-full rounded-md bg-neutral-900 border border-white/50 border-dashed px-2 py-6'>
				<Layout.Paragraph>
					{width} x {height}
				</Layout.Paragraph>
			</div>
			<Layout.Caption>Resize your browser to see changes</Layout.Caption>
		</Layout>
	);
}
```
